Questions fréquentes

Pourquoi pas un template ou WordPress ?

Parce qu'un modèle acheté est conçu pour tout le monde, donc pour personne. On écrit chaque site de zéro : l'architecture correspond à votre besoin réel, et le code est documenté.

À qui appartient le code du site ?

À vous. Le code vous est remis à la livraison et il est lisible. Si un jour vous travaillez avec quelqu'un d'autre, tout part avec vous.

Que se passe-t-il après la mise en ligne ?

Soit vous repartez avec votre site et vous le gérez comme vous l'entendez, soit vous nous confiez le webmastering : hébergement, entretien, mises à jour. Dans les deux cas le code reste le vôtre.

Méthode

Faire avancer un projet, sans brouillard.

Des étapes visibles, des livrables nommés et un rythme de décision clair. Pour un site comme pour une mission de conseil.

  1. 01

    Cadrer

    Un atelier de lancement, puis une restitution sous 2 à 5 jours ouvrés.

    • Note de cadrage
    • Périmètre priorisé
    • Hypothèses, dépendances et planning
  2. 02

    Concevoir

    Validation par jalon ; les retours sont regroupés pour garder le rythme.

    • Architecture des contenus
    • Parcours clés
    • Direction visuelle et maquettes
  3. 03

    Construire

    Point d'avancement hebdomadaire pendant la production.

    • Site ou produit développé
    • Intégrations prévues au périmètre
    • Environnement de recette
  4. 04

    Recetter

    Une phase de recette guidée avant la mise en ligne.

    • Liste de vérifications
    • Corrections de recette
    • Plan de mise en ligne
  5. 05

    Transmettre

    Passation à la livraison ; suivi continu uniquement si le webmastering est retenu.

    • Accès et documentation utile
    • Prise en main
    • Cadre de support, si souscrit
