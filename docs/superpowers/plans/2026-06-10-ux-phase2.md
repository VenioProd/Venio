# UX phase 2 — dev workspace, pédagogie, mon-espace

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** Livrer les améliorations secondaires validées : vue « Ma journée », ⌘K + raccourcis et tri côté dev, vélocité cockpit en style financial timeline, création de séance depuis le calendrier ICS, templates à la création, UI documents pédagogie, et deux widgets mon-espace (À valider dev, Prochaine séance).

**Tech Stack :** identiques phase 1. Vérification : `npm run typecheck && npm run lint && npm run test`.

**Découpage en 3 volets disjoints :**
- Volet A (dev) : `src/pages/admin/dev-workspace/**`

- Volet C (mon-espace) : `src/pages/admin/mon-espace/**` (importe les services dev/education en lecture seule)
